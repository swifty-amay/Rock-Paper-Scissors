# Rock,Paper & Scissor
A classic yet famous game developed totally using Swift for native iOS users.

## Description
Well, you might be thinking of it as a normal game but here's the trickier part, you will be shown system's choice but you'll also be shown an option that whether you have to
**Lose** or **Win** in order to win the game and based on that you have to click the respective buttons.
Although this might seem easy but the challenge is to try to answer correctly within seconds, just like **The Card Guessing Game** I developed in C++ if you have seen it!

## Topics Covered
Well it do not cover bigger advanced topics but ya, this game covers essential SwiftUI topics which would be required in almost every app while building it. The topics that are
reflected in this project are as follows :-
- @State property
- How to shuffle arrays
- Creating random numbers within a range
- Stack views such as VStack, HStack and ZStack
- Game logic implementation using 'switch case'
- Radial Gradient
- How to show alerts, buttons
- Creating custom views
and many more.

Building this project was a lot of phone. Hope that you'll enjoy playing it. Have fun...
